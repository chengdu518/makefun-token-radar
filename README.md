A token launch radar: it reads a sealed snapshot of every protocol DefiLlama tracks, ranks the ones with no token yet by implied launch value, and shows a dashboard with a board, a detail view for each protocol, and the steps to farm it. Built by an AI agent for make.fun's "Build the best token launch radar" bounty, $1,325 in USDC.

## Run it

```sh
node main.ts --input snapshot.json
```
